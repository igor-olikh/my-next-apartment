# Как запустить

Папка проекта: `my-next-apartment`. Все команды — из этой папки.

## Открыть

На этом компьютере: [http://127.0.0.1:5173](http://127.0.0.1:5173)

На сервере: `http://сервер:8080`

Ты только смотришь страницу. Цены сами обновляются раз в неделю (воскресенье, 6:00 по Мадриду).

## Этот компьютер

Первый раз:

```bash
npm install
npm run dev
```

Потом каждый раз только:

```bash
npm run dev
```

Подожди пару секунд. Открой [http://127.0.0.1:5173](http://127.0.0.1:5173)

Остановить: в терминале `Ctrl+C`.

Страница — порт 5173. Цены — порт 8080. Нужны оба. `npm run dev` поднимает оба.

## Сервер

```bash
docker compose up -d --build
```

Открой `http://этот-компьютер:8080`

Стоп:

```bash
docker compose down
```

## Редко

Проверить, что ничего не сломалось:

```bash
npm test
```

Снять цены прямо сейчас, не ждать воскресенья:

```bash
npm run collect
```

Снимок цен: `data/snapshots/latest.json`

## Как само проверяет цены

Отдельной кнопки нет. Будильник сидит внутри той же программы, что отдаёт страницу.

Срабатывает само в двух случаях:

1. **Воскресенье, 6:00 по Мадриду.** Программа сама заходит на открытый индекс Fotocasa, снимает цены Аликанте и Эль-Кампельо, записывает файл `data/snapshots/latest.json`. Страница при открытии читает этот файл.
2. **При старте.** Если последним ценам больше 6 дней (или цен ещё не было) — снимает сразу, не ждёт воскресенья. Если цены свежие — ничего не трогает.

Если Fotocasa не ответил: старые цифры остаются, внизу страницы будет ошибка.

Важно: программа должна быть запущена. `npm run dev` на маке или Docker на сервере. Выключил компьютер / контейнер — будильник не тикает. На сервере с `docker compose` это как раз то, что должно работать всегда.
