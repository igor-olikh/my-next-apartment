# Следующая квартира

Личный брифинг жилья в Аликанте и Эль-Кампельо.
Цены снимаются сами. Ты только открываешь страницу.

Как запускать: [docs/zapusk.md](docs/zapusk.md)

## На сервере

```bash
docker compose up -d --build
```

Открой `http://сервер:8080`.

Раз в неделю по воскресеньям в 6:00 по Мадриду система сама берёт индекс Fotocasa и обновляет снимок. Если снимок старше 6 дней — обновит при старте.

## На этом компьютере

```bash
npm install
npm test
npm run dev
```

Страница: http://127.0.0.1:5173
Сбор вручную: `npm run collect`

Данные лежат в `data/snapshots/latest.json`.
